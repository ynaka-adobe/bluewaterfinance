# cards-blog

Custom **cards** block. Purpose: blog post listing.

## Authoring (Document Authoring)

Model: `standalone`

Cards convention: 2 columns, one row per post.

| Cards Blog |                                                                                     |
| ---------- | ----------------------------------------------------------------------------------- |
| image      | Heading with the post link, byline, date, excerpt, and a "continue reading" link last |

Paragraphs between the heading and the excerpt (byline, date) are shown as the small meta line.

## Supported variations

No variations.

N/A (Document Authoring project)
